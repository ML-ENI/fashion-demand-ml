# Repository instructions for Codex

## Visualizations

Before creating, editing, reviewing, or exporting any chart, figure, dashboard, or model-evaluation visualization in this repository, read `docs/visualization-rubric.md` completely and apply it as the visual source of truth.

This requirement applies to charts in Python modules, notebooks, reports, and generated assets. If a task-specific user instruction conflicts with the rubric, follow the user instruction and update the rubric only when explicitly requested.

The local notebook `notebooks/eda/visualizacion_graficos.ipynb` is an ignored design laboratory. It may be consulted for executable examples, but it is not the canonical specification and must not be committed.
